# Ceynix Games

Site du studio. Hébergement Railway depuis la branche main.

## En local

Node.js 22 ou supérieur. Aucune dépendance à installer.

```sh
npm start
```

Ouvrir http://localhost:3000. Railway fournit automatiquement la variable PORT.

Les candidatures sont préparées et copiées localement. Ajouter le lien Discord et les coordonnées du studio pour permettre leur envoi.
